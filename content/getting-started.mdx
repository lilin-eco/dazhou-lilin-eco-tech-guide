# 开始使用

## 使用前准备

向系统管理员取得当前环境的访问地址和个人账号，并确认所属公司、可见模块及项目职责。不要使用他人账号代办审批。指南网站不提供业务系统账号，也不收集密码。

开发、测试和演示环境只使用虚拟工程、人员和金额。正式业务地址及授权以实际交付安排为准。

## 第一次进入

1. 使用管理员提供的地址登录业务系统。
2. 核对顶部的“公司”，确认本次工作的主体。
3. 从项目管理进入“项目台账”，按工程或研发类型筛选。
4. 根据工作需要选择“全部项目”“我负责的”或“我参与的”。“全部”仍受权限限制。
5. 点击项目名称或“查看 / 办理”，核对项目编号、公司和状态，再执行操作。

如果公司为空、项目不可见或操作按钮缺失，先按 [常见问题](/faq/) 检查，不要重复创建项目绕过权限。
